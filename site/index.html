02 / SETUP

Run it on Windows.

Requires a supported Node.js version — verified on Windows x64 with Node.js 26. Review the plan before applying it; setup preserves unrelated settings and backs up existing configuration.

powershell — trace workbench
# install dependencies
npm ci

# configure development analysis tools
node bin/trace.cjs plan
node bin/trace.cjs apply
node scripts/link-grok-skill.cjs --plan
node scripts/link-grok-skill.cjs --apply

# verify the setup
node bin/trace.cjs doctor

Personal configuration, credentials, raw private analysis, and application binaries stay outside Git. PRs target 2–3 commits, max 4. See the repository rules before contributing.
