02 / SETUP

Run it on Windows.

Requires Windows x64, a supported Node.js version, .NET 9 SDK and Desktop runtime. Run from the repository, review each plan before applying it, then reconnect agent hosts. Setup preserves unrelated settings and keeps exact backups.

powershell — trace workbench
# install dependencies
npm ci

# install the pinned Windows engine
npm run computer:setup -- --plan
npm run computer:setup -- --apply
npm run computer:doctor

# connect agent hosts
npm run computer:config -- --plan
npm run computer:config -- --apply

Personal configuration, credentials, raw private analysis, and application binaries stay outside Git. PRs target 2–3 commits, max 4. See the repository rules before contributing.
