# TRACE Workbench 0.1.0 — prepared release notes

Prepared 27 October 2026. This candidate is not merged, tagged or published. Final owner approval and exact-artifact gates remain required.

TRACE supplies shared local analysis and Windows computer-control tools for AI agents. The six Computer Use MCP tools support exact window selection, PNG/accessibility observation, fresh single-use actions, verified outcomes and desktop-session cleanup. The method library connects routing, effect checks and resumable checkpoints; it does not replace host reasoning or permission controls.

## Included capabilities and evidence

- Pinned static analysis and honest optional-provider diagnostics; four preserved client registrations and matching managed skill guidance.
- Native desktop ownership, visible nonactivating glow, supervised input, physical Escape stop, durable quarantine and explicit verified recovery.
- Exact window geometry, configurable accessibility depth, stale/consumed observation rejection and honest `not_dispatched` / `unknown` outcomes.
- Scoped mouse, keyboard, scrolling, drag/drop, modal, moved-window and Unicode clipboard behavior.
- Actual Codex and Claude workflows; synthetic native REPLAY recording, privacy edits, offline audio, two exports and a causal pause before end.
- [Requirement-to-evidence checklist](REQUIREMENT_EVIDENCE_REVIEW.md), [owner-invariant review](PRODUCTION_OWNER_RECONCILIATION.md) and [final gate review](FINISH_GATE_REVIEW.md).

## Supported scope and retained limits

Windows x64, supported Node.js, .NET 9 SDK/Desktop runtime, normal-integrity unlocked interactive desktop and accessible UIA targets. Coordinate evidence is limited to the declared single-monitor modes. Human input and unrelated automation can interfere.

Recovery coverage combines compatible retained sources; three older cells lack the later separate native-owner-exit field. Controlled held-input and acknowledgement-failure cases keep their stated scope. Original failures remain preserved under approved replacement decisions. Walkthrough review is sampled. Required host workflows do not establish semantic image comprehension or model-host REA analysis.

Broader display/DPI transitions, secure/elevated desktops, independent background GUI workers, optional native analysis providers and Grok/Gemini live workflows are not promoted. No provider speech-quality claim follows from synthetic offline audio.

## Installation and delivery

Use the [README setup commands](../README.md#computer-use-setup), [operation/recovery guide](COMPUTER_USE.md) and [archive verifier](ARCHIVE_INSTALL.md). Configuration plans preserve unrelated entries and exact backups. Reconnect existing MCP hosts after updating source.

The delivery candidate must include a source/setup ZIP, acceptance manifest and SHA-256 checksums. Verify installation and rollback from those exact ZIP bytes on hosted Windows CI; a rebuilt or differently versioned archive does not inherit that acceptance. `npm` publication is not part of this release (`private: true`). After reviewed integration and explicit owner approval, the intended GitHub tag is `v0.1.0`.
